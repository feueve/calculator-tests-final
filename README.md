# Автотесты для онлайн-калькулятора дат (calculator.net)

Данный проект содержит набор автотестов на Python + Selenium для проверки функционала страницы [Date Calculator](https://www.calculator.net/date-calculator.html).

## Описание сценариев
В рамках задания реализованы следующие проверки:
1. **Корректный расчёт (Форма 1)** — 5 наборов данных для вычисления разницы между датами (включая високосные года, переходы через год и проверку одинаковых дат).
2. **Граничные значения (Форма 1)** — проверка работы с минимальным (1000) и максимальным (9999) годом.
3. **Ограничения ввода (Форма 1)** — проверка автоматического обрезания года при вводе 999999 (до 9999).
4. **Корректный расчёт (Форма 2)** — прибавление и вычитание дат (включая переход через високосный февраль).
5. **Пустые поля (Форма 2)** — проверка, что пустые поля автоматически заменяются на `0`.
6. **Неверный ввод (Форма 2)** — ввод букв в числовые поля (проверка текста ошибки: *"Please provide a valid month."*).
7. **Слишком длинное число (Форма 2)** — ввод значения `9999999999999` (порог переполнения калькулятора), проверка текста ошибки: *"The input is out of range..."*.
8. **Поведение Clear/Reset** — проверка сброса значений и повторного расчёта после очистки полей.
